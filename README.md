# Write prettier LaTeX: refactored

This is the refactor branch of prettytex. This readme will be updated while the refactor progresses.





## Documentation

We finally have documentation. Everything important is written down in the style-files, but we also have a “proper“ documentation in the docs folder. Just read the [prettytex.pdf](docs/prettytex.pdf).


## Installation

We have an installer now! Simply get the `installer.py` from the installer-directory and execute in anywhere on your system. Currently, it is set to automatically make a global install (at least on Linux, other operating systems still need some testing). But you can either install from master or refactor.
